# Contact Us form

**Issue type** Feature

**Application** Automation Exercise

## Description

Let visitors send a message and attachment to the store.

## Test coverage

Draft one independent test case per scenario. Use the numbered acceptance criteria for traceability.

As a visitor, I want to send a message with an attachment so I can share details with the store.

**Preconditions**
Start on the home page. Prepare a test name, valid email, subject, message, and local sample file.

[Automation Exercise test case 6](https://automationexercise.com/test_cases)

### Acceptance criteria

1- The home page is open | The visitor selects **Contact Us** | The **Get in Touch** form is visible.
2- The contact form is visible | The visitor fills the four fields, attaches the sample file, and selects **Submit** | A confirmation dialog offers **OK**.
3- The submission dialog is open | The visitor selects **OK** | The page displays a submission success message.
4- The submission success message is visible | The visitor selects **Home** | The storefront home page opens.
