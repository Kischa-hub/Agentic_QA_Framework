# Add a review on a product

**Issue type** Feature

**Application** Automation Exercise

## Description

Let shoppers submit feedback from a product detail page.

## Test coverage

Draft one independent test case per scenario. Use the numbered acceptance criteria for traceability.

As a shopper, I want to submit a review so I can share feedback on a product.

**Preconditions**
Start on the home page. Choose a product and prepare a test name, valid email, and review text.

[Automation Exercise test case 21](https://automationexercise.com/test_cases)

### Acceptance criteria

1- The home page is open | The shopper selects **Products** | The **All Products** page opens and displays product cards.
2- The catalog displays the chosen product | The shopper selects its **View Product** link | The detail page displays the **Write Your Review** form.
3- The review form is visible | The shopper enters the test name, email, and review and selects **Submit** | The page displays `Thank you for your review.`.
